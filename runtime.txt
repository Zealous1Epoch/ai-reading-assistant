项目一：智能读书助手 — AI 辅助阅读工具                                              2025.09-2026.05
【技术栈】
Python、FastAPI、LangChain、ChromaDB、DeepSeek API、React

【项目描述】
独立开发的 AI 辅助阅读 Web 应用。用户上传 PDF/EPUB/TXT 电子书后，系统自动识别目录并切分章节，基于 RAG（检索增强生成）技术实现书籍内容的语义搜索与智能问答，并提供多种 AI 分析工具辅助深度阅读。

【主要工作】
· 实现 RAG 问答流程：将书籍章节向量化存入 ChromaDB，用户提问时检索相关段落作为上下文，调用 DeepSeek 大模型生成回答并标注引用来源
· 设计三种对话模式（当前章节/整本书搜索/跨书综合），分别适配不同深度的阅读提问场景
· 开发 6 个 AI 分析工具（总结、背景调研、思维导图、书籍推荐等），为每个工具设计 Prompt 模板实现结构化输出
· 使用 FastAPI 搭建后端 API 并支持 SSE 流式输出，React 编写前端交互界面
· 完成 Docker 容器化并部署至 Railway 云平台

【项目收获】
· 理解了 RAG 技术栈的核心链路：文档解析 → 文本分块 → 向量化存储 → 语义检索 → LLM 生成
· 实践了从前端到后端到部署的完整 Web 应用开发流程
· 锻炼了产品思维：从自身阅读需求出发，独立完成需求分析、技术选型到功能迭代的全过程
