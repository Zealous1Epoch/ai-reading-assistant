# PageOn 桌面版安装说明（写给书友）

## 一、下载安装

- **Mac（Apple 芯片）**：下载 `PageOn-3.9.1-arm64.dmg`
- **Windows（64 位）**：下载 `PageOn Setup 3.9.1.exe`

（改名前发给书友的旧包仍叫「读书助手」，功能一样，不用追着换。）

### Mac 第一次打开
因为没买苹果官方签名，双击会提示"无法验证开发者"。这样处理：

> 对着 app **右键（按住 Control 点击）→ 打开 → 再点"打开"**，只有第一次需要这样。

### Windows 第一次安装
安装或首次运行会弹蓝色"Windows 已保护你的电脑"：

> 点 **"更多信息" → "仍要运行"**。

## 二、第一次启动：填 AI 配置（重要！）

装好后打开是空的，**必须配一个大模型才能用**（PageOn 的解析、问答都靠它）。

1. 点右上角 **设置**（齿轮图标）；
2. 填三项（用自己的 DeepSeek 最省事）：
   - 接口地址：`https://api.deepseek.com`
   - 模型名：`deepseek-chat`
   - API 密钥：去 https://platform.deepseek.com 注册后创建，充 10 块钱能用很久
3. 点"测试连接"，绿了就保存，立刻生效。

> 有公司内部/其他 OpenAI 兼容接口的，接口地址和模型名换成自己的即可。
> 不配大模型也能浏览，但上传书解析、AI 问答会是灰色。

## 三、你的数据存在哪

- Mac：`~/Library/Application Support/SmartReader`
- Windows：`%APPDATA%\SmartReader`

藏书、划线、笔记、聊天记录都在自己的电脑里，不上传任何服务器（除你配置的 AI 接口本身）。
卸载 app 不会删数据；想彻底清空就顺手删这个文件夹。

## 四、出问题怎么办

1. 先完全退出再重开（第一次冷启动可能要等半分钟转圈，别急）；
2. 还不行就把日志发给慧姐：
   - Mac：`~/Library/Logs/PageOn/reader-server.log`（旧版装在 `~/Library/Logs/读书助手/`）
   - Windows：`%APPDATA%\PageOn\logs\reader-server.log`（旧版在 `%APPDATA%\读书助手\logs\`）

## 给慧姐：怎么出新版安装包

1. 本地 mac 包（随时可出）：
   ```bash
   cd backend && ../venv/bin/python3 -m PyInstaller reader.spec --noconfirm \
       --distpath ../build/reader-dist --workpath ../build/reader-work
   bash ../scripts/sign_adhoc.sh ../build/reader-dist/reader-server
   cd ../desktop && npm run dist:mac   # 产出 desktop/release/*.dmg
   ```
2. **Windows 包只能靠 GitHub Actions**（PyInstaller 不能跨平台交叉编译）：
   改完代码推 tag（如 `v3.9.1`），等 Actions 跑完，Releases 页自动挂上双平台安装包。
   手动触发：仓库 Actions 页 → "Build Desktop Installers" → Run workflow。
